Omnier is the company brain for sales. There is no separate database of deals. The files are the brain.

You and your agent edit the same files. The web app shows those files. Signal ingestion rewrites those files. There is one source of truth.

## Git

Each team workspace is a git repo.

- Ingestion commits after each signal that updates files.
- Your agent should commit after it changes files.

Git is the full history of every file. Use it to see how `context.md` changed and when.
