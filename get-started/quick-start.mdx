Paste this into Claude Code, Codex, or any other agent:

```text
Connect Omnier MCP at https://mcp.getomnier.com/mcp

Then show the authentication url to the user, so they can create an account.

When the user is back, load get_started and onboard the user to Omnier.
```

## If you need to add MCP yourself

URL: `https://mcp.getomnier.com/mcp`

**Claude Code (CLI)**

```bash
claude mcp add --transport http omnier https://mcp.getomnier.com/mcp
```

Then type `claude`, run `/mcp`, select `omnier`, and authenticate.

**Codex (CLI)**

```bash
codex mcp add omnier --url https://mcp.getomnier.com/mcp
```

Then type `codex`, run `/mcp`, select `omnier`, and authenticate.

**Desktop:** add a custom MCP server named **Omnier** with that URL (Claude: Customize → Connectors. Codex: Settings → MCP servers → Streamable HTTP).
