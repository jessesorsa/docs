## Claude Code (Desktop)

1. Open the **Customize** tab → Click **Connectors** → Add → add custom connector.
2. Add name **Omnier** and MCP server URL:
   ```text
   https://mcp.getomnier.com/mcp
   ```
3. Login in and connect. For new users send a message to **jesse@getomnier.com**

## Claude Code (CLI)

1. Add Omnier:
   ```bash
   claude mcp add --transport http omnier https://mcp.getomnier.com/mcp
   ```
2. Type `claude`, then `/mcp`. Select `omnier` and authenticate.
3. Login in and connect. For new users send a message to **jesse@getomnier.com**

## Codex (Desktop)

1. Open **Settings** → Click **MCP servers** → **Add server** → choose **Streamable HTTP**.
2. Add name **Omnier** and MCP server URL:
   ```text
   https://mcp.getomnier.com/mcp
   ```
3. Login in and connect. For new users send a message to **jesse@getomnier.com**

## Codex (CLI)

1. Add Omnier:
   ```bash
   codex mcp add omnier --url https://mcp.getomnier.com/mcp
   ```
2. Type `codex`, then `/mcp`. Select `omnier` and authenticate.
3. Login in and connect. For new users send a message to **jesse@getomnier.com**
