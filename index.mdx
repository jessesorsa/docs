Omnier is a self-updating **system of context** for your agent to plan, run and record sales tasks. Key ideas:

1. Omnier turns signals from email and meetings into tasks and context for your agents, automatically in the background
2. The context files live in a cloud directory, so any of your agents can read and write them, from anywhere
3. The Omnier to-do list renders directly in your agent chat, allowing you to run tasks without manually prompting your agent

## Omnier MCP tools

| Tool | Role |
| --- | --- |
| **`read_skill`** | Loads skills the agent needs to use Omnier efficiently. |
| **`query`** | Reads your workspace (todo lists, files) freely using SQL. |
| **`action`** | Writes (create, update, delete todo lists and files) to your workspace freely using SQL. |
| `show_todo_list` | Shows a live UI view of the todo list directly in the agent chat. |
