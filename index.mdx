Omnier is a sales To-Do list for your agents. It's the **system of action** your agent uses to plan, run and record sales tasks.  Key ideas:

1. Omnier automatically turns signals from email, CRM, and meetings into a prioritised list of tasks for you and your agent
2. The to-do list is available directly in your agent chat, and at [https://app.getomnier.com/home](https://app.getomnier.com/home).

## Omnier MCP tools

| Tool | Role |
| --- | --- |
| **`read_skill`** | Loads skills the agent needs to use Omnier efficiently. |
| **`query`** | Reads your workspace (todo lists, documents) freely using SQL. |
| **`action`** | Writes (create, update, delete todo lists and documents) to your workspace freely using SQL. |
| `show_todo_list` | Shows a live UI view of the todo list directly in the agent chat. |
