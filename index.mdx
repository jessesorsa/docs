Omnier is a markdown based CRM for AI agents.

1. Your customer records, playbooks, and automations live in your Omnier workspace, as plain markdown files.
2. Connect your apps. The actions you take update the sales markdown files in your workspace automatically in the background. 
3. The files stay up to date, so your agent always has the current context to accurately run your sales. See and edit every file yourself in a simple file view.

## Omnier MCP tools

| Tool | Role |
| --- | --- |
| **`load_omnier_skill`** | Loads useful Omnier skills for your agent. |
| **`read_file`** | Reads a file from your CRM. |
| **`write_file`** | Creates or updates a file in your CRM. |
| **`bash`** | Freely runs commands in your CRM. |
