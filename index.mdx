Omnier is a sales To-Do list for you and your agents. It's the **system of action** your agent uses to plan, run and record sales tasks.  Key ideas:

1. Omnier enables your agent to turn signals from email, CRM, and meetings into a prioritized list of daily tasks
2. The task list renders directly in your chat, so both you and the agent can run it together

## Omnier MCP tools

| Tool | Role |
| --- | --- |
| **`read_skill`** | Loads skills the agent needs to use Omnier efficiently. |
| **`query`** | Reads your workspace (todolists, documents) freely using SQL. RLS applied for all queries. |
| **`action`** | Writes (create, update, delete todolists and documents) to your workspace freely using SQL. RLS applied for all actions. |
| show\_todo\_list | Shows a live UI view of todays todo list in the agent chat. |
